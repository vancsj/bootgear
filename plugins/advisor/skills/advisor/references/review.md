# Adversarial review

Ask for objections and attack angles.
Give the decision as it stands, supporting facts with sources, fixed constraints, excluded options with reasons, and impact.
Mark unverified facts. Keep preferred fixes and private author reasoning out.

For direct communication, start with:

> You are an adversarial advisor. Use only the text below. Do not run commands, read files, or fetch web sources.

For persistent advice, start with:

> You are an adversarial advisor. Inspect the named primary artifacts and sources independently within the assigned scope.

Give the artifact paths and applicable standards. Allow scoped reads, checks, and authoritative lookups as needed.
Keep the caller's role, permissions, and handback limits. Present claims as test targets.

- For a decision, request the strongest objections and attack angles.
- For an open problem, ask what assumptions can fail and what a different framing shows.
- For a settled conclusion, ask what would make it false and what evidence would show that.
