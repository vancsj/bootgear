# Deputy question and answer standards

## Scope

- Save only decisions in the deputy store. Save facts in the memory ledger.
- Save a standing decision when one question can state its scope and decision.
- Keep decisions with one vote. Votes show recurrence.

## Question

- Write one general question per entry. Use a separate question for each scope.
- Omit session, branch, pull request, finding, pass, slate, and date.
- Omit option lists and `or`, `either`, `(a)`, or `A:`.
- Omit pronouns, including `I`, `me`, `my`, `you`, `your`, `it`, `its`, and `itself`.
- Use active voice and approved, plain words. Use established names.
- Use 20 words or fewer in each sentence.

## Answer

- Write one option per answer. Give each answer an ID, such as `a1` or `a2`.
- Omit pronouns. Use 20 words or fewer in each sentence.
- Omit bare letters and numbers, such as `A` and `2`.
- Give a different answer the next ID as a rival on the same entry.

## Votes and reasons

- Count one vote per file for an existing answer. Give a different answer zero votes when you start its rival.
- Count a combined file once per question it answers.
- Write the reason as one sentence with one clause. Omit semicolons.
- Use the fixed confirmation sentence for assertions. Use session evidence for legacy votes.
## Excluded from general votes

- Exclude session-only notes, pinned rules, and project-only decisions.
- Store project-only decisions in their project.

## Hard gates

Keep production changes, outward sends, irreversible actions, goal sign-off, and mutation permissions with the user.
