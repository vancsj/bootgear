# Spec review contract

The artifact is reviewed by fresh converge roles so the author cannot certify
their own requirements or design. The review is about correctness and
completeness: whether the request can be settled, the design fits the existing
architecture, alternatives were considered where necessary, and the result is
proportional. Severity and blast radius help prioritize a finding but do not
decide whether a requirement is complete.

Use the original request as the intent source, repository code/tests/docs as
current-behaviour evidence, and the active settlement's source-of-truth order
for contested domain facts. A choice is not a factual finding; leave it for
`spec-debate` after `resolve` cannot settle it.
