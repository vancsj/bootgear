# Contributing

Contributions are welcome under the [Apache License 2.0](LICENSE). By
submitting a contribution you agree it is licensed under those terms
(Apache-2.0 §5).

## Sign your commits (DCO)

Every commit must carry a Developer Certificate of Origin sign-off:

```
Signed-off-by: Your Name <your.email@example.com>
```

Add it with `git commit -s`, or turn it on for every commit:

```sh
git config format.signOff true
```

The sign-off certifies the [Developer Certificate of Origin 1.1](https://developercertificate.org/):
you wrote the change, or otherwise have the right to submit it under the
project's license. Pull requests with unsigned commits fail the DCO check.

If you contribute on your employer's time or equipment, make sure your
employer allows you to submit the work under Apache-2.0.
